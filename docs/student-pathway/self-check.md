# 自评——30 秒定位你在哪一层

老实回答，不要选"应该是"的答案，选"实际是"的答案。

## 第 1 题：你上次让 AI 干活是什么时候？
- A. 就是打开这个包之前，我还没正式用过 → 你在 L0 之前
- B. 用过，但每次都要重新解释一遍背景 → 你在 L0
- C. 我会一次把背景写清楚，AI 基本能懂 → 你在 L1 或以上

## 第 2 题：AI 昨天帮你做的东西，你现在能找到吗？
- A. 找不到，都在聊天记录里翻 → 你在 L1
- B. 存了，但是乱放的，找起来要想一下 → 你在 L2
- C. 有固定位置，我知道去哪找 → 你在 L2 或以上

## 第 3 题：AI 会不会主动提起你之前说过的偏好或决定？
- A. 不会，每次都要我重复 → 你在 L2
- B. 偶尔会 → 你在 L3
- C. 经常会，甚至会提醒我之前的坑 → 你在 L3 或以上

## 第 4 题：有没有任务是你不在电脑前，AI 自己完成的？
- A. 没有，我必须一直盯着 → 你在 L3
- B. 有一两个定时任务，但不太稳定 → 你在 L4
- C. 有稳定运行的自动化，我只看结果 → 你在 L4 或以上

## 第 5 题：你能说出自己常用的专属工具/流程有哪些吗？
- A. 说不出来，都是随手问 → 你在 L4
- B. 能说出 1-2 个 → 你在 L5
- C. 能说出 3 个以上，而且知道为什么用它们 → 你在 L5，可以往深了钻

## 结果判定

选择最靠后的那个答案对应的层级，就是你现在的位置。从那一层的 `L{n}-xxx.md` 开始读。

**不要跳级。** L2 没打牢就去搞 L4 自动化，是给自己埋雷——自动化放大的是你的习惯，好习惯放大是效率，坏习惯放大是灾难。
