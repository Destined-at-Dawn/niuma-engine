# Contributing

Contributions are welcome!

## How to Contribute

1. Fork this repository
2. Create a feature branch (`git checkout -b feature/xxx`)
3. Commit your changes
4. Push to the branch (`git push origin feature/xxx`)
5. Create a Pull Request

## Contribution Directions

- New agent adapters
- Rule optimization and additions
- Documentation improvements
- Translations (templates in other languages)
- Bug fixes

## Rule Writing Standards

- Each rule must include: principle, trigger signal, practical steps, anti-patterns
- Must not contain personal information or project-specific paths
- Use constraint language (must / must not / shall not)
